That last command reproduces the available aggregate-only artifact using the


## Team 2 can train using the matching saved matrix

The new joblib contains custom classes. `src/features/pipeline.py` must remain
importable from the repository root when loading it. It is not interchangeable
with the earlier all-one-hot artifact; an old fitted price model cannot use it.

```python
import joblib
import pandas as pd
from scipy import sparse
from sklearn.linear_model import Ridge

preprocess = joblib.load("models/preprocess.joblib")
X_train = sparse.load_npz("data/master/X_train_full_oof.npz")
rows = pd.read_csv("data/master/train_full_oof_rows.csv")
assert X_train.shape[0] == len(rows)
assert X_train.shape[1] == len(preprocess.get_feature_names_out())

model = Ridge(alpha=1.0)
model.fit(X_train, rows["y_log"].to_numpy())

# Run only when the validation file is available locally.
val = pd.read_csv("data/master/val_features_full.csv", low_memory=False)
X_val = preprocess.transform(val)
y_pred_log = model.predict(X_val)
```

If rebuilt with detailed flags, first join the matching validation cohort:

```python
from src.features.pipeline import attach_imputed

cohort_val = pd.read_csv("data/master/val_cohort_imputed.csv", low_memory=False)
val = attach_imputed(val, cohort_val)
X_val = preprocess.transform(val)
```

Do not train a model on `preprocess.transform(train)`: its target encodings use
the full-training maps. Use the included OOF matrix or call `fit_transform` with
the log target when fitting a new transformer.

## Model selection with outer folds

The preprocessor belongs inside the estimator pipeline, so each outer training
fold learns its own encoders, scaler, medians, and target means. Keep duplicate
groups together in the outer split too. Do not pass the already encoded full
OOF matrix to cross-validation: its encodings can use outer-validation targets.

```python
import numpy as np
import pandas as pd
from sklearn.model_selection import GroupKFold, cross_validate
from sklearn.pipeline import Pipeline
from sklearn.linear_model import Ridge
from src.features.pipeline import CarPreprocessor

train = pd.read_csv("data/master/train_features_full.csv", low_memory=False)
y_log = np.log1p(train["price_vnd"])
estimator = Pipeline([
    ("preprocess", CarPreprocessor(variant="full", random_state=42)),
    ("model", Ridge(alpha=1.0)),
])
scores = cross_validate(
    estimator, train, y_log,
    groups=train["duplicate_group_id"],
    cv=GroupKFold(n_splits=5), scoring="r2",
)
```

This example was not run on the real dataset and is not a reported benchmark.
The upstream imputation and category grouping already present in the CSV also
need refitting within outer folds for strictly fold-isolated raw-data evaluation.

`brand_retention_rate` and `province_price_index` are excluded by default because
their existing values depend on training prices. To retain the original frozen
full feature set for the fixed train/validation protocol, explicitly add
`--include-frozen-price-stats` when rebuilding. Report that feature choice in the
benchmark. Do not use that option in outer CV without rebuilding those statistics
inside each outer fold. Neither `build_features.py` nor its saved statistics is changed.
